Agent Feedback Log

Shared by Nick Palenchar on November 4, 2026

The Agent performance dashboard compares ratings by harness, model and effort. The new Agent Feedback Log, linked from it, is a page that lists every response given on agents' work, newest first, across all canvases. It can be filtered by canvas, repository, project, period, harness, model, effort and rating, and grouped by configuration, project, repository, canvas, week or month. Each card links back to the card, and the page links back to the dashboard.
