Project plan

Feedback on agent performance

Optional feedback after approval, connected to the model configuration, project and card that produced the work.

01Attribute and retain feedback

Keep feedback as local metadata with a link to the card and the actual harness, model and effort. Account for missing attribution and multiple configurations.

02Capture optional feedback

Offer a configurable, skippable prompt after approval. Approval and landing continue even if feedback is skipped or cannot be saved.

03Explore a performance dashboard

Decide the useful comparisons with the owner, then visualize feedback with sample counts and links to its evidence.

Future task complexity and type can enrich comparisons. Recommendations based on feedback remain future work.
