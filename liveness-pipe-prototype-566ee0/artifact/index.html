Liveness-pipe prototype: evaluation

Can a small supervisor between Obeya and each agent clean up the agent's processes when Obeya, or the supervisor itself, dies?

Verdict: combine it with the registry, don't adopt it alone, and keep it out of Obeya's launch path for now.

The two faults that made the first Codex integration roll back are fixed in the prototype and covered by tests on macOS and Linux. It still cannot help when Obeya and the supervisor die together, and it would replace Obeya's graceful stop with an instant kill. Making it the real launch path belongs to the crash-recovery workstream (W3).

How it works

  • Obeya dies: its end of the liveness pipe closes, and the supervisor kills the agent and everything it saw under it.
  • Supervisor dies: Obeya kills everything the supervisor had reported, as long as each process is still the one that was reported.
  • The pipes never reach the agent, so the agent can't keep the supervisor alive by accident.

The two faults that stopped the first integration

Supervisor killed

Before: the agent survived, still holding the supervisor's output, and Obeya waited for that output to end forever.

Now: Obeya reacts to the supervisor's exit itself and stops the agent and its separately started child; an unrelated process is untouched.

Agent exits at once

Before: a child the agent started in its first moments, before the first sample, kept running.

Now: on the agent's exit the supervisor also stops the agent's whole process group, which reaches that child.

Each test was checked to fail with its fix removed. Obeya now sees the agent's own process number, not the supervisor's.

Before agents are launched through it

  • Normal stop: closing the pipe kills at once. Graceful stop (waiting for busy turns) stays as it is today; the pipe is only for Obeya's death.
  • Apps: an app the agent started dies with the session, also one kept from parking, which matches the earlier decision that a crash ends session work. Work outside the agent (containers, remote hosts) is not reached.
  • Platforms: macOS and Linux only; Windows needs a different mechanism (W5). The packaged app still has to start the bundled supervisor correctly.
  • Remaining gaps: sampling can miss a child that leaves the agent's group quickly; on macOS a reused process number within the same second passes the check; every kill by number can race with reuse.
  • Both agents: Claude's processes also survived Obeya's death in earlier probes, so this should be one launch path for Claude and Codex.
