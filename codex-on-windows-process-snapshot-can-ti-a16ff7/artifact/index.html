A slow first process snapshot no longer ends the session

The first PowerShell and CIM launch can take longer than the former three-second limit. The startup snapshot now has fifteen seconds to establish process ownership.

A later snapshot still uses the short limit for normal operation. If that snapshot times out, it gets one fifteen-second retry. Other inspection failures still stop the session.

The regression test exercises the cold budget, retry and failure behavior. A native Windows snapshot check runs in the Windows build workflow.
