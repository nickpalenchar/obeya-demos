What is already fixed

Commit 6971a5a8, landed November 4, switches active tracking to asynchronous process snapshots on macOS, Linux and Windows. Tracking and cleanup stay ordered, and cleanup still verifies process creation identities before signalling anything.

The blocking process-table reader is now used only for crash recovery at startup, before the server begins serving pages.
