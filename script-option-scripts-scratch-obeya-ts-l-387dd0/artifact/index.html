Finding a scratch Obeya without guessing

Workers often lost track of where their scratch Obeya lived and searched /tmp/obeya-scratch-* or guessed paths that do not exist. Staging now prints the home, repository, database and server log paths, and --list prints the same for every running instance. Everything below is real output from this branch (login tokens shortened).

1. Stage two instances from different stage files, then list them

Each staging prints home, repo, database and log next to url and port. --list gives one line per running instance and names its stage file, so a worker can tell which is theirs. (Port 4480 is another worker's instance, which was running at the time.)

Instances staged into a custom directory (--dir or the stage file's dir) are listed too, and --login, --stop, --say and --artifact find them by port alone. The script's header and the repository's run setting now say: "--list and the stage output give home, repo, database and log paths; do not grep /tmp/obeya-scratch-*."
