Test suite no longer leaves stray bun -e setInterval processes

The fix is already on main (commit a612f541, “End test helper processes when their runner exits”, landed this morning). This card verified it and needed no further code change.

How it works

Every idle helper process a test starts first connects to a private local socket held open by the test runner. When the runner ends, however it ends (normal exit, crash, kill -9, a hung run cut off by a timeout), the operating system closes that socket and every helper exits by itself, including detached grandchildren that outlived their parent.
