A failed agent now shows in red

A card whose agent could not start, or died with an error, gets a red frame, a “!!” pin and the state “Agent stopped with an error”, next to the orange “!” of a question for you.

Root cause of the Codex errors: Obeya refused to start Codex wherever the repository had a .codex folder (“Codex project configuration is not supported yet”). It now lets you trust that configuration explicitly, and errors that remain go straight to you instead of leaving the card “at work” with no agent.
