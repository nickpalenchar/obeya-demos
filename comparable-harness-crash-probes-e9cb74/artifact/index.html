What survives when an agent or Obeya dies

Real Claude and Codex workers on real cards, macOS 26.6.2 · Claude Code 2.1.316 · Codex CLI 0.162.0 · 15 measured runs, 0 blocked · each in its own scratch repo and Obeya home

Each worker started an app (a heartbeat in a process group of its own), asked a question, and Obeya's parking checked app.keep, which said keep it. Then the probe killed the agent process or the Obeya server with SIGKILL and looked 8 seconds later. An unrelated canary process ran throughout.

The unrelated canary survived every run. After an Obeya kill, both agents exited on their own (their input closed). Every run's processes were cleaned up afterwards.

Is the app meant to keep running?

  • Codex, agent killed: stopping it is the documented behaviour: work the session started ends with the session, whatever app.keep says (app.keep only governs parking of waiting cards).
  • Claude, agent killed: nothing in the design says. Claude workers have no process tracking, so the app lives on while Obeya runs and could clean it up. The two harnesses behave differently here.
  • Either harness, Obeya killed: a crash runs no cleanup, as documented, so the app is orphaned. Recovering it safely is the next workstream (W3).
Found along the way: after the Codex agent dies, its app is killed, but Obeya then logs on the card that the app “keeps running while the card waits”, the opposite of what happened. Proposed as a separate card.

What the owner sees

With Obeya still running, the card keeps asking its question; only an error line in its log (“Claude Code process terminated by signal SIGKILL” / “Codex app-server exited (SIGKILL)”) shows the agent is gone. After an Obeya kill the card is unchanged. What answering that question would do next was not tested.

Not covered

Linux and Windows; an agent killed mid-turn rather than while waiting; apps in the agent's own process group; resuming after the crash. In one Claude run, another Claude process of the server (not the worker) and its MCP helpers were still alive 8 s after Obeya was killed.
