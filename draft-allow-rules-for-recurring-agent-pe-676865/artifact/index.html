Scope to understand before trusting

These patterns match command text. A wildcard can span spaces, slashes and additional arguments; a directory name is a convention, not a filesystem boundary.

Tests and demo scripts execute code. Browser input and JavaScript can submit forms or make network requests. Narration uses your configured voice service and may incur charges.

The absolute paths match this machine’s recorded commands. Different paths, wrappers, sandbox checks and existing ask/deny policies can still produce questions. A test followed by another shell command does not automatically approve that other command.

One-off shell editing and copying, installation of browsers or voices, pushes and deployments have no dedicated allowance here. The general wildcard limitations above still apply.

  3. New Claude sessions load the trusted configuration. Codex’s own prompts remain governed by Codex.
