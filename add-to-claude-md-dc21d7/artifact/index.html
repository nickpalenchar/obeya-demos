CLAUDE.md: two new rules

Added after the bullet on tests and typecheck

Never wait with sleep or polling chains in the foreground (sleep 25; …, until curl …; sleep 3): a hook blocks them. Run long commands (bun test --parallel, bun run typecheck, a scratch Obeya start) with run_in_background or Monitor and wait for the notification; for a short wait on a port use one bounded timeout 30 bash -c 'until curl -sf http://127.0.0.1:<port>/ >/dev/null; do sleep 2; done'.

Added after "No project-specific logic in the core"

The extension design (docs/plan/extensions.md) is best effort: not every feature fits it cleanly, and the core may be extended where needed. A worker promoting a feature into an extension should expect other features to have seeped into the code it moves, and edits those itself.
