Configure which artifacts a handover may bring

Three kinds: video, HTML / screenshots, data schema changes (the schema page). Set per repository (canvas) and as a machine default.

1. Machine default: Configuration → Demos

Applies to every repository that sets nothing itself. Saved in demo.json; all three by default.

2. Per canvas: the repository's settings (default shown)

3. Set for this repository: video and schema off

The last of video / HTML cannot be switched off, since every handover brings a demo. The value can be taken over into .obeya/settings.json as demo.artifacts.

What the worker sees

  • The brief names only the allowed kinds (no video: "make an HTML artifact"; no schema: no schema-page instruction).
  • ready_for_review refuses a demo of a kind not allowed, and without schema has no data_models field and the data-model tripwire does not run.
  • Precedence: repository settings, then demo settings (demo.json), then all three.
